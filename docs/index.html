luci-app-disk-health

路由器硬盘健康监控 · 支持 NAND 闪存类型一键切换的寿命估算

OpenWrt 22.03 / 24.10 ImmortalWrt 24.10 iStoreOS License: Apache-2.0 Maintainer: sugarfreecoke

这是什么

luci-app-disk-health 是一个 OpenWrt / ImmortalWrt / iStoreOS 的 LuCI 插件， 让你在路由器 Web 管理界面里直观地查看 NVMe / SATA / eMMC / USB 乃至 硬路由 NAND 闪存 的健康状态、剩余寿命与已通电时长。无需登录 SSH，打开「服务 → 磁盘健康」即可。

核心功能

📊
设备总览自动发现全部物理块设备，卡片化展示型号、容量、接口与挂载点。
🟢🟡🔴
健康分级良好 / 警告 / 危险 三色徽章，异常 SMART 属性自动高亮。
💽
多设备后端smartctl / mmc sysfs / UBI 擦除计数，按类型自动分派。
🔌
依赖自检缺 smartctl / mmc 时给出友好提示，绝不抛出 Lua 错误。
⚡
NAND 寿命估算UBI 擦除计数估算硬路由 NAND 剩余寿命，标注“估算值”。
🎛️
闪存类型一键切换卡片内 SLC/MLC/TLC/QLC 按钮，立即刷新寿命估算。

NAND 闪存类型切换（亮点）

硬路由（MT7981 / MT7986 / IPQ6000 等）只有 raw NAND，没有 NVMe / eMMC 那样的标准寿命寄存器。 本插件用「平均擦除计数 ÷ 额定擦写次数」估算剩余寿命，而额定次数芯片不暴露， 需要你按路由器实际颗粒选择。检测到 NAND 后，设备卡片内会出现一组按钮：

SLCMLC TLCQLC 自定义
类型典型额定擦写次数 (P/E)常见场景
SLC≈ 100,000企业 / 工业级，寿命最长
MLC≈ 10,000消费级路由器最常见
TLC≈ 3,000成本低、容量大，寿命较短
QLC≈ 1,000寿命最短
点击对应按钮，寿命估算立即刷新；若不确定颗粒类型，选「自定义」并填入厂商标称的 P/E 循环次数。 也可在「服务 → 磁盘健康 → 设置」里选择。
⚠️ 估算值说明：UBI 的擦除计数（EC）在重刷 / 格式化后会归零，历史磨损会丢失； 且裸 MTD（无 UBI）只能读到坏块与 ECC 失败，数据更粗。因此所有 NAND 寿命均为参考估算， 实际以厂商工具为准。

安装

按你的平台选择对应方式（三大平台均已提供验证过的离线安装包）：

OpenWrt / ImmortalWrt(opkg)
ImmortalWrt 24.10 (apk)
iStoreOS
SDK 编译
# 网页：系统 → 软件 → 上传 .ipk
# 或 SSH：
opkg update
opkg install luci-app-disk-health_1.0.0-1_all.ipk
# ImmortalWrt 24.10 默认 apk 包管理器
apk add --allow-untrusted luci-app-disk-health_1.0.0-1_all.apk
# iStoreOS：商店 → 本地安装 → 上传应用包
# 使用 istore-app-disk-health-v1.0.0.tar.gz
# 自带 install.sh / uninstall.sh，不走 opkg 限制
# 放到 OpenWrt 源码树后编译
mkdir -p package/luci-app-disk-health
cp -r luci-app-disk-health/* package/luci-app-disk-health/
./scripts/feeds update luci
make menuconfig   # LuCI → Applications → luci-app-disk-health
make package/luci-app-disk-health/compile V=s

使用

  1. 安装后浏览器打开 LuCI → 服务 → 磁盘健康。
  2. 首屏立即出现，采集在后台进行；可点「重新检测」强制刷新，或勾选自动刷新。
  3. 若是硬路由（仅有 NAND），在设备卡片内点 SLC / MLC / TLC / QLC / 自定义 切换寿命基准。
  4. 「服务 → 磁盘健康 → 设置」可调整采集频率与告警阈值。
